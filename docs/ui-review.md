# 操作流程与 UI 联动检查

保持现有视觉风格，优先修复“页面看起来成功，但真实状态不同”的问题。

## 本轮修正

- 管理状态以服务器验证结果为准，不以 sessionStorage 是否有字符串为准；过期凭据及时退出管理状态。
- 按账号/管理身份隔离请求数据，切换身份清理详情、规则预览和关联缓存；旧请求的 abort 不再覆写新请求 loading。
- 列表不携带完整正文，详情按需请求；显示加载、失败和重试。抽屉支持焦点限制、返回原焦点、背景滚动锁定，输入控件不误触方向键翻页。
- 访客“已关闭”可真正查看并恢复；收藏和已读过滤读取本机状态；批量已读只作用于可见条目。
- 访客偏好合并入口登录后仍可见，包含屏蔽词；服务端超过额度会拒绝，不默默截断后清空本机数据。
- 个人规则预设导入、增删关注词、规则操作使用当前作用域，不误调全局管理接口；失败不显示成功。
- Webhook/Telegram 凭据区分展示。Webhook 不再要求 Bot Token；配置完成前不能开启，错误明确提示。
- Webhook 凭据显式保存，避免失焦保存与“测试”竞争。未保存状态提示，切换渠道确认并暂停推送；清除 Token 确认并关闭 Telegram。
- 配置保存不再整页卸载/闪烁；服务器夹紧联动阈值后输入更新，预览失效；操作期间禁止重复提交。
- 个人立即攒批只发本人队列；免打扰时手动发送需确认。小时额度仍生效。
- 完整推送面板按实际渠道命名，重置规则需确认并关闭推送，不把个人缺凭据错误指引到站长环境变量。
- 浏览器 hash 联动保留 `#me`；注册名额已满回跳显示登录错误。
- 移动端导航自动把当前页签滚入可见区，头像可直达个人中心；退出个人页返回资源流。普通登录后仍保留独立管理登录入口，受限管理域名明确提示，不误报密码错误。

## 后续可选，而非本轮直接重构

- 为复杂推送路由提供逐项草稿、统一保存与离开提醒，替代所有筛选项的即时保存。
- 把管理操作统一迁移到 `/api/admin/*`，便于反代白名单；旧接口需要明确兼容期。
- 数据达到十万级后再评估全文索引、游标分页、预计算聚类，以及采集/推送 Worker 分离。
- 多实例或高流量公开站应使用反代共享限流/缓存与监控，不应只靠单进程内存护栏。

## 布局、配色与阅读密度专项

- 延续冷灰侧栏、白色画布，不用大面积渐变或装饰图；靛蓝标识选择/焦点，绿色标识免费/成功，琥珀标识兑换码/时效，红色只用于风险和失败。
- 桌面侧栏限制在视口高度，数据源分组默认收起，可独立滚动，不再把整页撑成巨大的空白画布。
- 顶栏保留所在空间和页面，导出/全站计数仅在资源流出现；不同页面的操作不再混杂。
- 资源流采用“频道标题与解释 → 频道导航 → 分类 → 常用筛选 → 列表”。分类和高级条件从视觉上降一级，常用筛选保留；高级筛选可折叠但生效条件仍可见、可清除。
- 清除条件保留当前频道，切换为“全部收录”使用单独按钮。高级“形态全部/方式全部”真正移除默认限定；空态文案区分收藏、已关闭与普通频道。
- 列表默认显示标题和元信息两层；“显示摘要”是独立、可记忆的密度设置，不影响结果。已读仅降低标题强调，不把整条和操作按钮变得难读。
- 个人推送改为“配置渠道 → 测试投递 → 开启推送”的顺序引导，步骤只定位控件，绝不自动真实发送。显示投递/队列/额度摘要，低频免打扰设置折叠。
- 配置页按任务分区，而不是等高填满所有卡片；加入解释阈值的分段提示，完整规则和关注/屏蔽成为真实跳转入口。
- 关注与屏蔽分开介绍，明确全站/个人范围，避免把“全部来源”误称为“全局权限”。添加屏蔽使用普通主按钮，删除和失败才强调红色。
- 手机保留紧凑阅读与可点击操作区，检查 390px、1024px、1440px 布局无横向溢出；抽屉和个人页沿用相同语义色与控件层级。

## 分类管理联动

- 来源固定分类、RSS 栏目/标题过滤均有管理表单，区别于兜底提示；统一单实例源编辑器，跨桌面/手机不再出现两份独立编辑状态。
- 管理端可试算误判反例、预览历史变化并确认修正；普通用户不可修改全站分类。
- 管理员在详情可人工移动分类/形态、备注或恢复自动；人工锁定跨采集、AI 和历史重整保持。
- 手动移动或源规则变化立即使列表/统计/热点缓存失效，RSS ETag 包含内容变更，不再因为 ID 没变就错误返回 304。原 AI 说明和人工分类区别显示。

## 本轮：结构拆分与筛选收口（证据）

- 把长在 `App.tsx` 里的三块稳定 UI 拆成独立组件：`FeedToolbar`（频道条件 + 计数 + 视图）、`ActiveFilters`（可移除的筛选胶囊）、`SourcePanel`（快捷视图 + 数据源树，桌面与移动共用）。`App.tsx` 由 2205 行降到 1939 行，行为不变。
- 筛选胶囊的 × 改为真正的按钮，带 `aria-label`，键盘与读屏可逐个移除；清除动作从四处（工具栏、筛选条、侧栏、胶囊）收拢为：Feed 内「全部清除」一处，移动端筛选面板折叠时由摘要条提供「清除」。
- 频道条件、结果计数与视图切换合为一行，并在列表滚动时固定在顶部；移动端筛选面板把「快捷视图与数据源」折叠为默认收起的二级区，芯片与筛选控件排在其前。
- 实测证据：`.bench/ui/review-fix-browser.json` 增补——Feed 内仅一个清除入口；带 1600px 占位内容滚动 300px 后工具栏 `top≈0`；移动端胶囊高 54px 且数据源默认收起；「全部清除」后筛选状态归零。
- 文档：README 分类数从 27 修正为实际的 28（补 `lottery`），README.en 同步；文档站侧栏新增「工作台结构与数据边界」，`npm run docs:build` 通过。
